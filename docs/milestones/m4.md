# M4: ITC Reconciliation, Invoice Checking & Form GSTR-3B Table 4 Return Preparation

What Milestone M4 and M4b added to GST Copilot: deterministic rule-based invoice matching, statutory discrepancy explanations, single-invoice validation, and traceable Form GSTR-3B Table 4 return compilation directly from reconciliation.

---

## 1. Reconciliation Engine & Synthetic Data

- **Synthetic Generator (`gst_copilot.recon.synth`, ADR 0019, 0022):**
  - Generates paired Purchase Register (books) and Form GSTR-2B datasets with realistic tax scenarios.
  - **Easy mode:** single-issue planted discrepancies per invoice across 10 distinct categories.
  - **Hard mode (`--hard`):** combined multi-issue discrepancies:
    - Format + amount difference.
    - Typo + amount difference.
    - Typo + tax period difference.
    - Twin suppliers with identical invoice amounts and numbers.
    - Boundary tolerance testing: exact Rs 1.00 rounding boundary vs Rs 1.01 discrepancy.

- **Matcher Accuracy & Benchmark (`gst_copilot.recon.matcher`, ADR 0020, 0022):**
  - Multi-pass deterministic matching pipeline.

| Dataset | Metric | Baseline | Final | Target | ADR |
|---|---|---|---|---|---|
| Easy data (seeds 1–10) | Precision / Recall | 1.0 / 1.0 | **1.0 / 1.0** | >= 0.95 | 0020 |
| Hard data (seeds 1–10) | Precision / Recall | 0.812 / 0.852 | **1.0 / 1.0** | >= 0.95 | 0022 |

Evaluated with:
```bash
python -m gst_copilot.recon.score --seeds 1-10 --hard
```

## 2. Statutory Invoice Checker (`POST /check-invoice`, ADR 0023)

- Validates single inward/outward invoices before posting or filing:
  - Required fields presence (invoice number, date, GSTINs, taxable value, tax components).
  - Supplier and recipient GSTIN format & Mod-36 checksum verification.
  - Two-digit Place of Supply state codes.
  - Arithmetic integrity: Taxable Value + IGST + CGST + SGST + Cess = Total Value within Rs 1.00 tolerance.
- Stateless, fast, independent endpoint returning verified/unverified rule flags.

---

## 3. Statutory Explanations & Citations (ADR 0026)

Every reconciliation category returns deterministic statutory guidance based on the CGST Act, 2017 and CBIC Circular No. 170/02/2022-GST:

- **Plain-language explanation** of why the discrepancy exists.
- **Actionable taxpayer next steps** (e.g. follow up with supplier, claim credit, or hold in reserve).
- **Form GSTR-3B placement** (e.g., Table 4(A)(5), Table 4(B)(2), Table 4(D)(2), or Excluded).
- **Exact statutory citations** (e.g. Section 16(2)(aa), Section 16(2)(b), Section 17(5), Section 16(4), Rule 36(4)).

---

## 4. Form GSTR-3B Table 4 Return Preparation (Milestone M4b, ADR 0027)

Compiles an auditable draft Form GSTR-3B Table 4 (Eligible ITC) directly from invoice matching results:

- **Table 4(A)(5) All other ITC:** Gross eligible credit auto-populated from GSTR-2B (`exact`, `period_diff`, `amount_diff`, `format_diff`, `typo_diff`, `missing_in_books`).
- **Table 4(B)(1) Permanent Reversals:** Ineligible ITC under section 17(5) and Rules 38, 42, 43.
- **Table 4(B)(2) Temporary Reversals:** Invoices missing in books under s.16(2)(b) (Circular 170 Para 4.3(C)) and excess on amount diffs.
- **Table 4(C) Net ITC Available:** Computed as `4(A) - [4(B)(1) + 4(B)(2)]`.
- **Table 4(D)(1) Reclaimed ITC:** Credit reversed in prior months now reclaimed (`period_diff`).
- **Table 4(D)(2) Ineligible ITC:** Credit restricted by Section 16(4) / Place of Supply rules.
- **Exclusions:** Invoices missing in GSTR-2B (`missing_in_2b`) excluded from Table 4 under s.16(2)(aa) & Rule 36(4).
- **Auditability:** Every row and tax component (IGST, CGST, SGST, Cess) lists contributing invoice IDs (`invoice_refs`).

Available via:
- `POST /reconcile` (JSON payload includes `draft_3b`).
- CLI: `python -m gst_copilot.recon <folder> --gstr3b`.
